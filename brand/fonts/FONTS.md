Every font in this kit is open-licensed under the SIL Open Font License 1.1. The fonts are installed from npm as `@fontsource-variable` packages and bundled into the built site, so no page fetches a font from a third-party server. The license text of each font is copied next to this file.

| Geist Mono | `@fontsource-variable/geist-mono` | 5.3.0 | The Geist Project Authors | [OFL-1.1](OFL-geist-mono.txt) |
| Inter | `@fontsource-variable/inter` | 5.3.0 | The Inter Project Authors | [OFL-1.1](OFL-inter.txt) |

The logo wordmark does not use any font. Its letters are drawn as SVG strokes by `scripts/build-logo.mjs`.
