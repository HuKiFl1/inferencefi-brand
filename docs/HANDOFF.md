# IF-M2 handoff

This is the design contract HuKiFl1 is handing to 0xMelchizedek for milestone IF-M2: a brand kit and screen designs for swap, pools, liquidity and the agent dashboard, with Arc UI role tokens, so the protocol side can confirm they can be built with [Arc UI](https://uiarc.dev/) free components only, and can later implement IF-W5 against it.

It is not a live product, not a deploy, and not a replacement for the protocol `web/` Vite starter. The screens in this repository are a read-only preview with static mock data. They never connect a wallet, sign or send.

The coded screens in `app-screens/` and the PNGs in `design/` are the visual source. There is no Figma file. The spec allows "Figma, or the same thing in another file," plus an export into `design/`.

Working name: Inference Finance (short form InferenceFi). Official name (IF-D1) and visual brand (IF-D2) are proposals awaiting the yes the spec requires for those decisions; see [IF-D1-D2-BRIEF.md](IF-D1-D2-BRIEF.md). Until then, keep the working name and this kit.

## What to copy into `web/` later

Do not replace the protocol Vite starter from here. When you implement IF-W5, copy or install these pieces into `web/`:

1. Tokens: `brand/tokens.json` (source of truth) and `brand/tokens.css` (generated by `npm run tokens`). Map the CSS variables onto the document, including a light and a dark set via `data-theme`.
2. Type: families, weights and the scale in `brand/TYPE_SCALE.md`. Geist, Geist Mono and Inter are SIL OFL; see `brand/fonts/FONTS.md`. Self-host them. Do not fetch fonts from another origin.
3. Logos and illustrations: `brand/logo/` and `brand/illustrations/`. The React wrappers are `shared/brand/Logo.tsx` and `shared/brand/Illustration.tsx`.
4. Arc free components: install from the public registry only, `https://uiarc.dev/r/{name}.json`, with the shadcn CLI, as in `shared/components.json`. Use only items on the free list in `shared/arc-tiers.lock.json`. No Arc Pro, no Pro registry, no Pro token.
5. Screens: treat `app-screens/src/screens/` and the PNGs listed below as the state-by-state contract. Rebuild them in `web/` against the real read-only SDK, still with Arc free components and these tokens. No raw hex, `rgb()`, `hsl()` or `oklch()` in first-party UI code.

Vendored Arc components stay MIT. Their copyright notice ships in `shared/components/arc/LICENSE`.

## Inferred SDK fields

The mock in `app-screens/src/mock/sdk.ts` is shaped like the read-only CLI described in the spec: `infer pools`, `infer quote`, `infer rates`, `infer rewards`. Amounts are decimal strings, as an SDK would serialise bigint values for JSON. Every coin is a TEST mock. Every rate is a placeholder, not a market price.

**None of these field names have been confirmed against `@inference-finance/sdk` 0.1.0.** That SDK lives in the protocol repo, which is still local to 0xMelchizedek. Treat every name below as inferred. Please confirm or correct them before the screens are treated as a spec. Additive fields are fine; a silent rename is not.

## Companion framing

Keep the marketing site and the app copy consistent with these public references:

- [HuKiFl1/inferencefi-stableswap](https://github.com/HuKiFl1/inferencefi-stableswap): clean-room StableSwap reference and test vectors for the Inference Finance AMM on HyperEVM testnet. FLOP integration is through credits, spend receipts, escrow and channels, not a FLOP-native module.
- [HuKiFl1/inferencefi-oracle](https://github.com/HuKiFl1/inferencefi-oracle): RateOracle policy vectors and a read-only deviation monitor.
- [HuKiFl1/Flop](https://github.com/HuKiFl1/Flop): stale-channel reclaim. After N stale blocks plus a W-block challenge window, payout order is provider, then lender principal, then payer. A TCLK timeout makes a refund eligible; a claim with an accepted preimage wins until the refund is included. Do not contradict these rules.
- IF-D8 (hook `jobId` as a Flop receipt root) has a HuKiFl1 design and test-vector companion. It is a proposal pending the spec owner and the yes required by the open IF-D decisions. Do not present it as adopted, and do not wire a receipt root into the screens until that decision is made.

FLOP and Pearl are sources of credits. The AMM is a separate protocol. Do not describe it as hosted by FLOP.
